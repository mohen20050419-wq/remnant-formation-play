# 残阵 Remnant Formation · 网页试玩版

《残阵》是一款抽牌落子、摆阵共鸣、明牌破阵的 2D 单机卡牌肉鸽。这是**开发中的试玩版**（画面与数值仍在打磨）。

**开始游戏**：等待加载条走完后，点击画面内「开始新一局」。

- 操作：鼠标（悬停手牌放大、右键棋盘格落子）；键盘/手柄亦可
- 进度会保存在浏览器本地（IndexedDB）；换浏览器或清除站点数据会丢失
- 建议桌面端 Chrome / Edge / Firefox 全屏游玩（1280×720 基准）

## 玩法一分钟

1. 每回合从手牌**落子**到 3×5 棋盘（卡牌一次性消耗，落子即弃）；
2. 同阵营连成线（≥4）触发**共鸣**——线的构成满足条件会升级为「名阵」变体（悬停空格可预览「差 N 张成型」）；
3. 敌人意图**全程明牌**，看准破绽摆位、拆线、送牌换资源；
4. 牌 hp 归零会**殉爆**——牺牲也是一种构筑。
